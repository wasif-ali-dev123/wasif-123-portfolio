# Project screenshots

Drop project screenshots here, then point each project's `image` field at them
in `src/data/portfolio.ts`, e.g.:

    image: "/projects/healthcare-billing.png",

Suggested filenames (matching the current projects):

- healthcare-billing.png
- elearner-automation.png
- event-driven-services.png
- techradar-commerce.png

Recommended size: 1280×720 (16:9). Until an image is set (`image: null`), each
card shows a clean placeholder panel automatically — no broken images.
